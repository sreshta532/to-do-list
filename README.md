# To-Do List Web App

## Overview

A clean, modern, and lightweight To-Do List web application built for **Web Development Internship Task 2**. The app enables users to manage daily tasks seamlessly with immediate UI updates powered entirely by Vanilla JavaScript without page reloads.

## Features

- **Add Tasks**: Quickly input and add new tasks to your list.
- **Mark Tasks Complete**: Toggle completed status with a clean visual strikethrough.
- **Delete Tasks**: Remove individual tasks with instant DOM removal.
- **Dynamic UI Updates**: Instant updates for adding, toggling, and removing tasks without reloading.
- **Empty State Feedback**: Displays an intuitive message when no tasks are present.
- **Responsive Design**: Clean, centered, mobile-friendly interface for all screen sizes.

## Technologies

- **HTML5**: Semantic document structure.
- **CSS3**: Modern custom styling, flexbox layout, and CSS variables.
- **Vanilla JavaScript**: Pure ES6 logic with zero external frameworks or libraries.

## Concepts Used

- **DOM Manipulation**: `document.getElementById()`, `document.createElement()`, `appendChild()`, `remove()`
- **Event Listeners**: Handling `click` and `keydown` events
- **Dynamic Element Creation**: Dynamically generating task items, labels, and action buttons
- **CSS Class Toggling**: Using `classList.toggle('completed')` for state styling
- **JavaScript ES6**: Arrow functions, `const`/`let` variables, and template literals

## How to Run

1. Open the project folder in **Visual Studio Code**.
2. Run using one of the following methods:
   - **With Live Server**: Right-click `index.html` and choose **"Open with Live Server"**.
   - **Direct Browser**: Double-click `index.html` or drag it into any modern web browser (Google Chrome, Edge, Firefox).
